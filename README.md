# Animais Incríveis

A front-end study project based on a course exercise, customized and expanded to practice JavaScript functionality and interactive web development.

The original project was provided as part of the course. I am not the original author of the project; this repository contains my own modifications, implementations, and experiments based on the original course material.

## Features

- [x] Menu mobile
- [x] Dropdown menu
- [x] Outside click
- [x] Scroll Animation
- [x] Accordion
- [x] Mondal
- [x] TabNav
- [x] ToolTip

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Project Purpose

The main purpose of this project is to practice JavaScript and explore how it can be used to create interactive and dynamic web interfaces.

The original course project was used as a starting point, while several features and behaviors were modified, implemented, and expanded as part of my own learning process.

## Concepts Practiced

- DOM manipulation
- Event listeners
- Click events
- Class manipulation
- JavaScript functions
- Conditional logic
- CSS animations and transitions
- Responsive design
- Intersection Observer
- Interaction between HTML, CSS, and JavaScript
